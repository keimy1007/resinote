# ResiNote — 眼科レジデント試験 2026

8科目を学ぶ一問一答アプリ。**834問（過去問145問・オリジナル305問・専門医試験384問）**。過去問は画像付き79問（資料画像61点）、元画像のない再現記録39問、文章問題27問です。オリジナルのうち35問にも提供資料の画像を使用しています。

公開URL：[ResiNote](https://keimy1007.github.io/resinote/)

## 学習機能

- 科目別の一問一答（10・20・50・全問、ランダム順も選択可）。解答入力欄・テストモードはなく、毎問その場で解説を確認
- 学習開始時は「過去問・覚えてない・ランダム出題」を初期選択。問題一覧から開始する場合は、一覧で指定した絞り込み条件を引き継ぐ
- 問題・解説の検索、過去問／オリジナル／専門医試験の出題元別、科目別、画像ありの絞り込み。専門医試験は年度（2024・2025・2026）でも絞り込み
- 全問に答え・解説・出題根拠。画像の拡大表示。問題文と解答をそれぞれコピー可能（学習中・結果画面）
- 「覚えた」「覚えてない」の2択を任意で手動チェック、覚えてない問題だけの再出題。チェック前の問題も「覚えてない」に含む。チェックを省略しても以前の記録は変えない
- ブックマーク、学習進捗、途中再開
- 学習記録はブラウザのlocalStorageに保存。ログイン不要・端末間同期なし

## 起動

Node.js 22以上。外部npm依存はありません。

```sh
npm test
npm run build
npm run dev
```

`http://127.0.0.1:4173/resinote/` を開きます。公開はGitHub Actionsが検証・ビルド後に`dist/`のみをGitHub Pagesへ配信します。

## 問題データ

`content/`内のUTF-8 TSVを編集します（区切り記号は`|`）。オリジナルの列は`topic|question|answer|explanation`。過去問は科目・出典・画像・解答照合状況も含みます。改行や`|`はフィールド内に入れないでください。問題IDは科目・問題文から生成されるため、並べ替えでは学習履歴が失われません。問題文の変更は別問題として扱います。

過去問の追加64問は`content/past-supplement.json`に収録。2009年口頭試問、2013・2019・2023・2025年の問題資料、2017・2018・2024・2025年の再現記録から、設問・出題論点を一問一答へ再構成しています。追加分の画像付きは18問・17画像。全問に元の設問や記録の位置と参考解答・確認用リンクを付けています。全文再現・全年度の完全収載ではありません。元の設問が文章のみの場合は「元画像なし」の表示を付けません。

表・症例・提供された学習テーマから展開した170問は`content/expanded.json`に収録。グループごとに科目・出典・必要な画像・参考リンクを持ち、`questions`の各要素は`[問題, 解答, 解説]`です。

2026年10月18日の見直しで、オリジナル530問を265問に厳選しました。試験範囲に明記された手技・工程、過去問の表や症例の別条件、所見からの鑑別・対応を優先しています。一般的な検査名だけを答える問い、略語の展開、同じ知識の細分化、過去問とほぼ同内容の問いを削除しました。科目ごとの件数を揃えるための水増しはしていません。バックリング手順の再現過去問、緑内障術後管理表①〜⑤の26問は残しています。

2026年10月20日に提供された緑内障学習テーマから、オリジナル30問を追加しました。薬剤9問、ハンフリー5問、プリザーフロ6問、眼底と視野2問、術後管理表2問、iStent関連6問。出題が確定した過去問とは区別し、全問に参考解答と確認用リンクを付けています。薬剤は国内電子添文、iStentは第3版の国内使用基準（inject W単独手術を含む）、視野と術後管理は取扱説明書・原著論文等を参照。新しい眼底画像は2019年レジ1・問7の写真部分で、選択肢の公式正答を再現したものではありません。既存794問の本文・ID・学習記録の扱いは変更していません。

PFMS周術期管理メモの問題は、2026年10月21日に33問から10問へ整理しました。術前準備・毛様体マイクロパルス・共通チェックポイント各1問、術翌日2問、1週・2週・2週〜1か月・ステロイド・EXGの管内糸各1問。時期ごとの確認事項と対応を直接問います。問題一覧で「PFMS管理」と検索すると10問に絞れます。PFMS管理以外の824問の本文・IDは維持し、書き直した10問は新しい問題として扱います。

PFMSのステントは管内10-0ナイロン、パルスは毛様体マイクロパルス、AVASは無血管性濾過胞として作成。早期一桁、2回×4セット、原則2週抜去、2週〜1か月の結膜抜糸、ステロイド半年などは「提供メモの方針」を問う前提を明示し、文献で検証された共通基準とは区別しました。マッサージの時間単位・加圧法などメモにない詳細は補っていません。術後11 mmHgの一律判定、加圧時だけのリークの無条件放置、TLEよりリークの予後が悪いという比較、EXGで閉塞予防のため必ず長期留置するという断定は採用していません。各問の解説と参考資料に、根拠を確認できた範囲と条件による違いを記載しています。

ローカル資料の網羅性は[2026年10月21日の照合結果](docs/local-source-audit.md)を参照。主要テーマの収録と、元資料の全設問・画像の収録は区別しており、完全網羅ではありません。

残した問題の本文・IDと保存キー（`resinote-v1`）は変更していません。公開URLは`/resitest/`から`/resinote/`に変わりますが、同じ`https://keimy1007.github.io`内のため、同じ端末・ブラウザの学習記録を使います。削除した問題の過去の記録は保存領域から消去しません。途中の学習に削除問題が含まれる場合は、その学習を終了して開始画面に戻します。

元資料はユーザー提供の「レジ試験対策2026.xlsx」と2009〜2025年の問題・解説・再現記録、網膜外科の試験対策資料です。オリジナルはこれらに出てくるテーマを展開し、無関係な専門領域を増やしていません。出題確率を統計的に推定したものではありません。旧形式PPT・動画・全過去年度の完全収載は行っていません。

画像付きの過去問は元資料を一問一答へ分割・再構成しています。テキストのみの再現問題は元画像がないことを明示します。緑内障など公式解答が資料にない設問は「参考解答」と表示します。全問の専門家査読は未実施です。

AMD分類、OVD、ベンチュリ流量など元メモの誤記・過度な断定を補正しました。追加過去問でも旧AMD治療、角膜内皮の六角形細胞率の単位などを見直し、装置固有の設定値を全例共通の正答にはしていません。参考リンクと編集方針はアプリ内「資料と出題方針」に記載。古いガイドラインも含むため、診療に際しては最新資料を確認してください。

## 専門医試験

[guchopoiの専門医試験カテゴリ](https://guchopoi.com/category/ophthalmologist-exam/)の直近3年（第36〜38回）の一般100問・臨床50問ずつ、計450問を分類しました。2024年 134問、2025年 130問、2026年 120問、計384問を8科目に収録しています。60問は医療制度・統計・眼瞼・涙道・眼窩などの範囲外、6問は掲載情報だけでは設問を確定できず保留です（2026一般61・72・84・85・87、臨床25）。

問題文・選択肢・掲載解説・画像の転載ではなく、出題された病態や検査を独自の一問一答に再構成しています。元の設問に対する選択肢の公式正答を示すものではありません。各問に年度・一般/臨床・番号、元解説の該当箇所へのリンク、学会の過去問題公開ページ、関連資料を表示します。2026年の学会公開PDFは確認できていません。

データは`content/specialist.tsv`（年度・区分・番号・科目・問題・答え・解説・参考資料ID）。全450問の採否と理由は`content/specialist-sources.json`に記録しています。IDは年度・区分・番号に固定しています。今回のオリジナル問題の厳選でも専門医試験384問は変更していません。

## 公開するファイル

元のExcel・PDF・Word・PowerPoint・画像フォルダ、名簿、採点表はGit管理と配信から除外しています。公開画像は`public/images/`に抽出した領域のみです。元資料の著作権は各権利者に帰属し、このリポジトリは元資料の再利用許諾を付与しません。外部Web画像は取得・転載していません。

ページには検索エンジン向け`noindex`を設定していますが、これはアクセス制限ではありません。GitHub PagesはURLを知る人が閲覧可能です。
